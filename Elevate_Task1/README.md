# Elevate Labs Data Analyst Internship

## Task 1: Data Cleaning and Preprocessing

### Objective
The objective of this task is to clean and preprocess a raw dataset by handling missing values, removing duplicates, standardizing data formats, and preparing the dataset for further analysis.

### Dataset
Netflix Movies and TV Shows Dataset

### Tools & Libraries
- Python
- Pandas
- NumPy
- VS Code
- Jupyter Notebook

### Steps Performed
- Imported the dataset
- Explored the dataset structure
- Identified missing values
- Filled missing values
- Removed duplicate records
- Renamed column names for consistency
- Converted the `date_added` column to datetime format
- Removed extra spaces from text columns
- Standardized text formatting
- Saved the cleaned dataset

### Files Included
- `Task1_DataCleaning.ipynb`
- `netflix_titles.csv`
- `cleaned_netflix.csv`

### Outcome
The dataset was successfully cleaned and is ready for exploratory data analysis and further data science tasks.
