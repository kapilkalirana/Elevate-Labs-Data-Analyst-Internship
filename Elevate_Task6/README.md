# Task 6: Sales Trend Analysis Using Aggregations

## Objective

Analyze monthly revenue and order volume using SQL aggregation techniques.

## Tools Used

* SQLite
* SQL
* SQLiteStudio

## Dataset

The analysis is performed using an online sales dataset containing order and transaction details.

## Analysis Performed

* Calculated monthly total revenue
* Calculated monthly order volume
* Grouped sales data by month
* Sorted results in chronological order

## SQL Concepts Used

* `COUNT()` for calculating order volume
* `SUM()` for calculating total revenue
* `GROUP BY` for monthly aggregation
* `ORDER BY` for sorting results
* `strftime()` for extracting month from dates

## Dashboard

Created a sales trend visualization dashboard to analyze:

* Monthly Revenue Trend
* Monthly Order Volume Trend

## Result

The analysis provides insights into monthly sales performance by identifying revenue trends and changes in order volume over time.
